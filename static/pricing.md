# Model Harga & Lisensi — Takerin

Dokumentasi resmi kebijakan harga dan ketersediaan fitur aplikasi Takerin untuk pengguna dan perayap AI (*AI agents*).

## Paket Gratis (Free Forever)

- **Biaya**: Rp 0 / bulan (100% Gratis Selamanya)
- **Model Monetisasi**: Bebas biaya langganan, tanpa donasi wajib, dan tanpa iklan.
- **Batas Pengguna**: 1 pengguna per akun pribadi.
- **Batas Periode Bulan**: Tanpa batas (arsip riwayat bulanan tersimpan aman).
- **Batas Kategori**: Bebas membuat dan menyesuaikan kategori tanpa batas kuota.
- **Batas Pencatatan Pengeluaran**: Tak terbatas (*Unlimited expense entries*).
- **Akses Ekspor Data**: Ekspor penuh ke file CSV dan ringkasan PDF kapan pun tanpa biaya tambahan.
- **Akses Platform**: Web responsif (desktop, tablet, mobile) dan Progressive Web App (PWA) yang dapat diinstal langsung di layar utama perangkat.
- **Privasi**: Tidak menjual data pengguna kepada pihak ketiga.

## Paket Berbayar (Pro / Enterprise)

- **Status**: Tidak Ada (*None*).
- Takerin tidak menyediakan fitur berbayar, tidak mengunci fitur di balik *paywall*, dan tidak memungut biaya apapun dari pengguna.
