# Internationalization & Bilingual Guidelines (i18n)

Pedoman dan standar internasionalisasi yang wajib dipatuhi oleh seluruh agent dan pengembang saat mengembangkan fitur, komponen, atau halaman baru di Takerin.

---

## 1. Prinsip Utama (Core Principles)

Aplikasi Takerin mendukung dua bahasa:
1. **Bahasa Indonesia (`id`)** — Bahasa utama (*default*) dan *fallback*.
2. **English (`en`)** — Bahasa sekunder untuk pengguna internasional atau preferensi personal.

Pengaturan bahasa pengguna disimpan di cookie `takerin_lang`, `localStorage`, dan tabel basis data `user_settings.language`.

---

## 2. Aturan Baku Kode (Coding Standards for i18n)

### A. Dilarang Keras Melakukan Hardcoding String Pengguna
Setiap teks yang dapat dibaca atau diakses oleh pengguna (*user-facing text*) **WAJIB** menggunakan pemanggil translasi `t('key.path')` dari `#lib/i18n/index.js`.
Hal ini mencakup:
- Teks konten markup HTML/Svelte (`<h1>`, `<p>`, `<span>`, `<button>`, dll.)
- Atribut elemen: `placeholder`, `title`, `aria-label`, `aria-roledescription`, `alt`
- Pesan status, notifikasi toast, alert konfirmasi, dan modal interaktif
- Pesan kesalahan validasi (*validation error messages*) baik di sisi klien maupun server
- Nilai fallback teks (contoh: gunakan `{user?.name ?? t('common.user')}` alih-alih `'Pengguna'`)

### B. 100% Paritas Kunci (*Key Parity*)
Setiap penambahan, pengubahan, atau penghapusan kunci translasi **WAJIB dilakukan secara berpasangan** pada kedua berkas:
- [`src/lib/i18n/id.json`](../../src/lib/i18n/id.json)
- [`src/lib/i18n/en.json`](../../src/lib/i18n/en.json)

Struktur objek JSON harus identik. Integritas paritas kunci diuji secara otomatis melalui unit test [`src/lib/i18n/i18n.spec.ts`](../../src/lib/i18n/i18n.spec.ts).

### C. Kepatuhan Terhadap `GLOSSARY.md`
Seluruh teks translasi dalam Bahasa Indonesia dan English wajib mengikuti nomenklatur resmi pada [`GLOSSARY.md`](../../GLOSSARY.md):

| Konsep Domain | Istilah ID (Wajib) | Istilah EN (Wajib) | Istilah Terlarang / Dihindari (*Avoid*) |
| :--- | :--- | :--- | :--- |
| **Periode Bulan** | Periode Bulan | Monthly Period | *Bulan kalender, billing cycle, cycle date* |
| **Tanggal Gajian** | Tanggal Gajian | Pay Date | *Start date, cycle date* |
| **Sumber Pemasukan** | Sumber Pemasukan | Income Source | *Salary, gaji (terlalu spesifik)* |
| **Pemasukan Bulanan**| Pemasukan Bulanan | Monthly Income | *Total income, budget total* |
| **Kategori** | Kategori | Category | *Pos, envelope, bucket* |
| **Kategori Tabungan**| Kategori Tabungan | Savings Category | *Investment category, saving bucket* |
| **Status Pembekuan** | Dibekukan | Frozen | *Archived, closed, deleted* |
| **Pengeluaran** | Pengeluaran | Expense | *Transaksi (terlalu umum), spending (noun)* |
| **Saldo Kategori** | Saldo Kategori | Category Balance | *Remaining budget, leftover* |
| **Ringkasan Bulanan**| Ringkasan Bulanan | Monthly Summary | *Report, monthly report, recap* |
| **Template Kategori**| Template Kategori | Category Template | *Budget rule, preset* |
| **Pengguna** | Pengguna | User | *Member, nasabah, klien* |
| **Administrator** | Administrator / Admin | Administrator / Admin | *Super user, staff* |

Unit test secara otomatis memverifikasi bahwa `id.json` tidak memuat kata `transaksi` atau `pos` (kategori), dan `en.json` tidak memuat kata `spending` (sebagai kata benda) atau `transaction`.

### D. Format Tanggal dan Waktu Sadar Locale (*Locale-Aware*)
- Jangan gunakan fungsi tanggal yang memaksakan singkatan bulan satu bahasa (seperti `formatDateIndonesian` statis) untuk antarmuka yang mendukung bilingual.
- Gunakan format tanggal yang dinamis mengikuti locale aktif pengguna (`id` atau `en`).
- Mata uang tetap Rupiah (`Rp` / `IDR`) sesuai batasan domain Takerin.

---

## 3. Pengecualian Khusus (Exceptions)

### Halaman Landing & Blog (`isIndonesianOnlyPage`)
Sesuai rancangan arsitektur pada `src/routes/+layout.svelte`:
- Halaman beranda publik (`/`) dan artikel blog (`/blog/*`) secara sengaja ditargetkan murni dalam **Bahasa Indonesia** untuk optimasi mesin pencari (SEO) target pasar lokal Indonesia.
- Pada halaman ini, atribut `<html lang="id">` dikunci ke Bahasa Indonesia.
- Seluruh halaman aplikasi terotentikasi (`/(app)/*`), alur pendaftaran/masuk (`/auth/*`), proses setup (`/onboarding`), konsol pengelola (`/admin/*`), dan mode offline (`/offline`) **wajib bilingual sepenuhnya**.

---

## 4. Checklist Pengujian Sebelum Commit (Pre-Commit Checklist)

Sebelum menyelesaikan implementasi fitur yang melibatkan teks antarmuka:
1. Jalankan `pnpm test src/lib/i18n/i18n.spec.ts` untuk memastikan paritas kunci 100% dan tidak ada pelanggaran glosarium.
2. Buka browser dan ubah bahasa di Pengaturan (`/settings`) dari **Bahasa Indonesia** ke **English** dan sebaliknya.
3. Pastikan tidak ada teks yang tertinggal (*untranslated string*), tidak ada teks *mixed language*, dan pesan error form muncul sesuai bahasa yang dipilih.
