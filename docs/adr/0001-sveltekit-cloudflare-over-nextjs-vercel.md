# SvelteKit + Cloudflare over Next.js + Vercel

Memilih SvelteKit yang di-deploy ke Cloudflare Pages menggunakan `@sveltejs/adapter-cloudflare` dibandingkan Next.js di Vercel. SvelteKit memberikan runtime overhead minimal (tanpa virtual DOM), eksekusi edge performan tinggi, bandwidth tanpa batas pada free tier Cloudflare, serta integrasi langsung dengan ekosistem Cloudflare (D1, KV, Workers).
